# سبزی و پھل منڈی کمیشن اینڈ انوینٹری اکاؤنٹنگ سسٹم (Mandi Accounting System)

یہ ایک مکمل **Core PHP (Non-MVC)** پروڈکشن ریڈی ویب و ڈیسک ٹاپ کمپیٹیبل اکاؤنٹنگ سافٹ ویئر ہے جو خصوصی طور پر پاکستان کی غلہ، سبزی و پھل منڈیوں کے کمیشن ایجنٹس (آڑھت) کے روایتی طریقۂ کار کے عین مطابق تیار کیا گیا ہے۔

---

### اہم خصوصیات (Key Features):

1. **کھاتے (Parties / Accounts)**:
   * زمیندار / کاشتکار (Farmers / Growers)
   * گاہک / دکاندار / بیپاری (Buyers / Shops)
   * بینک کھاتے (Bank Accounts)
   * دکان خرچ کھاتے (Shop Expenses)
   * کریڈٹ لمٹ اور بلیک لسٹ فلٹر۔

2. **مال آمد چالان (Maal Aamad / Inward Challan)**:
   * چالان نمبر، تاریخ، گاڑی/بلٹی نمبر، مارکہ (Marke جیسے NZ+JM, 786)۔
   * جنس اور پیکنگ (کریٹ، پیٹی، کاٹن، گٹو، ڈبی، ٹوکری)۔
   * ادا شدہ گاڑی کرایہ اور لوکل اڈا کرایہ۔

3. **خرید و فروخت / نیلامی بل (Daily Boli Sales)**:
   * گاہک کے نام روزانہ بولی بل کاٹنا۔
   * نگ، ریٹ، کمیشن کٹوتی (%) اور صافی رقم کا فوری حساب۔
   * **1-Click واٹس ایپ بل**: ایک کلک پر گاہک کو اس کے واٹس ایپ پر بل روانہ کرنا۔

4. **زمیندار بل / فردِ حساب (Fard Hisab Statement)**:
   * پوری لاٹ کی فروخت کی سمری۔
   * تمام منڈی کٹوتیاں: کمیشن، کرایہ کٹوتی، مزدوری، مارکیٹ کمیٹی فیس، منشیانہ، اور پیشگی رقم (Advance) کی ایڈجسٹمنٹ۔
   * خوبصورت A4/A5 پرنٹ ایبل فردِ حساب اور واٹس ایپ شیئرنگ۔

5. **بازار کھاتہ (Bazar Khata - صبح و شام کی وصولی)**:
   * شہر وائز گاہک فلٹر (سیالکوٹ، ڈسکہ، سمبڑیال وغیرہ)۔
   * صبح کی وصولی اور شام کی وصولی کا براہِ راست اندراج۔
   * بلیک لسٹ کسٹمرز کو چھپانے یا دیکھنے کا فوری آپشن۔

6. **چٹھہ بقایا جات (Chittha Recovery Sheet)**:
   * ریکوری آفیسرز کے لیے روزانہ صبح نکلنے والی چٹھہ لسٹ۔

7. **روکڑ کھاتہ (Daily Cash Book / روزنامچہ)**:
   * اوپننگ کیش ان ہینڈ، روزانہ کی کل آمد (نقد سیل + وصولیاں)، کل خرچ (ادائیگیاں، کرایہ، دکان خرچ) اور اختتامی کیش ان ہینڈ۔
   * آج کا نفع نقصان خلاصہ۔

8. **تفصیلی کھاتہ (Party Ledger)**:
   * کسی بھی زمیندار یا گاہک کا مکمل کھاتہ بنام و بجمع تفصیل۔

9. **سٹاک رپورٹ (Stock Report)**:
   * آمد، فروخت، اور منڈی میں موجود باقی سٹاک (Remaining Unsold Stock)۔

10. **ایک روزہ موازنہ (One Day Analysis Report)**:
    * فروخت بل رقم، وصولی جمع، اور ٹوٹل فرق کا روزانہ موازنہ۔

11. **ڈیٹا بیک اپ (One-Click Backup)**:
    * مکمل ڈیٹا بیس کا ایک کلک پر SQL بیک اپ اور ڈاؤن لوڈ۔

---

### استعمال کا طریقہ:

#### لوکل کمپیوٹر پر (Localhost / WAMP):
* براؤزر میں کھولیں: **`http://localhost/Fruit/`**
* ڈیٹا بیس `mandi_fruit_db` خود بخود بنا دیا گیا ہے اور تمام ٹیبلز فعال ہیں۔

#### آن لائن کلاؤڈ سرور پر (Live Cloud / cPanel / Shared Hosting):
* پورا `Fruit` فولڈر اپنے سرور کے `public_html` میں اپلوڈ کریں۔
* `config.php` میں اگر ضرورت ہو تو لائیو ڈیٹا بیس کا نام اور پاس ورڈ درج کریں۔
* `schema.sql` فائل کو اپنے لائیو سرور کے phpMyAdmin میں امپورٹ کر سکتے ہیں۔

### کی بورڈ شارٹ کٹس (Keyboard Fast Entry):
* **F1**: ڈیش بورڈ (Dashboard)
* **F2**: نئی بولی بل (Boli Sales)
* **F3**: نیا چالان مال آمد (Maal Aamad)
* **F4**: آمد خرچ واؤچر (Vouchers)
* **F5**: بازار کھاتہ (Bazar Khata)
* **F6**: روکڑ کھاتہ (Rokad Cash Book)
* **F7**: کھاتے رجسٹر (Parties)
* **F8**: چٹھہ بقایا جات (Chittha)
* **Enter Key**: فارم کے ایک خانے سے اگلے خانے پر خودکار فوکس (تیز رفتار ٹائپنگ)
